Histoire

La grande histoire du Web

Remonte le temps pour découvrir les événements qui ont marqué l'évolution du World Wide Web.

1989

Naissance de l'idée du Web

Tim Berners-Lee propose au CERN un système permettant de relier et partager des documents grâce à des liens hypertextes.

1991

Le Web devient accessible

Le projet World Wide Web est rendu public sur Internet, ouvrant progressivement l'accès aux premières pages Web.

1993

Le navigateur Mosaic

Mosaic popularise une navigation graphique avec des images intégrées dans les pages, rendant le Web plus accessible.

1994

Création du W3C

Le World Wide Web Consortium est fondé pour favoriser des standards Web ouverts et compatibles.

1995

JavaScript arrive

JavaScript permet d'introduire des comportements interactifs directement dans les navigateurs.

1996

CSS devient un standard

CSS1 permet de séparer la présentation visuelle du contenu HTML.

1998

Création de Google

Google développe un moteur de recherche qui transforme progressivement la manière de trouver des informations.

2004

Essor des réseaux sociaux

Le lancement de Facebook marque une étape importante dans le développement des plateformes sociales en ligne.

2005

Naissance de YouTube

La plateforme facilite la publication et le partage de vidéos sur le Web.

2014

HTML5 : une recommandation W3C

HTML5 devient une recommandation du W3C, consolidant de nouvelles fonctionnalités pour les pages et applications Web.

2020

Accélération des usages numériques

La pandémie de COVID-19 accélère l'utilisation des outils Web pour le travail, l'enseignement et les réunions à distance.

2022

Popularisation de l'IA générative

Le lancement public de ChatGPT contribue à populariser l'intelligence artificielle générative auprès du grand public.

Les codes de réponse HTTP

Lorsqu'un navigateur demande une ressource, le serveur renvoie un code de statut.

200

OK

404

500

Internal Server Error

Une erreur interne empêche le serveur de traiter la requête.

Les noms de domaine

Comment un site obtient-il son adresse ? Et comment ton navigateur le retrouve-t-il ?

Qu'est-ce qu'un nom de domaine ?

Un nom de domaine est un nom lisible par les humains, comme example.com, qui permet d'identifier une adresse sur Internet sans devoir mémoriser une adresse IP.

Les noms de domaine sont généralement enregistrés auprès de bureaux d'enregistrement appelés registrars. Un enregistrement est accordé pour une durée déterminée et doit être renouvelé.

Le cycle de vie d'un domaine

Découvre les grandes étapes de la vie d'un nom de domaine.

1. Disponible

Le nom peut être enregistré.

2. Enregistré

Un titulaire réserve le domaine.

3. Actif

Le domaine peut être configuré et utilisé.

4. Expiré

Sans renouvellement, il entre dans une procédure d'expiration.

Les délais de grâce, de récupération et de suppression varient selon les extensions et les registres.

Le DNS expliqué

Comment fonctionne le DNS ?

Quand tu écris une adresse dans ton navigateur, comment ton ordinateur sait-il où trouver le bon site ?

Pour comprendre, nous allons suivre le chemin parcouru par une demande DNS.

Pourquoi avons-nous besoin du DNS ?

Les appareils utilisent des adresses IP pour communiquer sur un réseau.

Mais retenir une adresse IP pour chaque site Internet serait difficile.

Le DNS, ou Domain Name System, est un système distribué qui permet notamment de retrouver les adresses IP associées aux noms de domaine.

Il joue un rôle comparable à un annuaire téléphonique : tu connais le nom d'un contact, et l'annuaire t'aide à trouver son numéro.

Nom de domaine ou adresse IP ?

Deux éléments différents qui travaillent ensemble.

Nom de domaine

example.com

Un nom facile à lire et à mémoriser pour les humains.

Adresse IP

192.0.2.1

Une adresse numérique permettant d'identifier une interface réseau pour acheminer des communications.

192.0.2.1 est une adresse réservée aux exemples et à la documentation. Elle ne représente pas l'adresse réelle de example.com.

Expérience personnelle

Quelle est ton adresse IP publique ?

Les serveurs sur Internet voient généralement l'adresse IP publique utilisée pour établir ta connexion.

Ton adresse IP publique

Non recherchée

Clique sur le bouton pour effectuer la recherche.

La recherche est facultative. Lorsque tu cliques sur le bouton, une requête sera envoyée à un service externe pour connaître l'adresse IP publique visible de ce service. Une connexion Internet est nécessaire. Aucune recherche n'est lancée automatiquement. L'adresse affichée peut être celle de ta box, de ton VPN ou d'un proxy, et non une adresse propre à ton appareil.

Adresse IP publique ou privée ?

Ton ordinateur peut utiliser différentes adresses IP selon le réseau.

IP privée

Utilisée à l'intérieur d'un réseau local, par exemple à la maison.

Exemple : 192.168.1.25

Elle n'est normalement pas accessible directement depuis un simple site Web.

IP publique

Adresse visible par un service externe lors de la connexion.

Plusieurs appareils peuvent partager une même adresse IP publique.

Elle peut changer avec le temps ou lorsqu'un VPN est utilisé.

Pour les utilisateurs
